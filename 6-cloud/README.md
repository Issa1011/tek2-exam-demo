# Cloud

Cloud betyder, at man bruger servere og services, som kører hos en udbyder.

Denne demo laver ikke rigtig deployment. Den viser kun simple kommandoer og begreber.

## Begreber

- IaaS: man lejer en server eller VM og styrer meget selv
- PaaS: man uploader sin app, og platformen håndterer mere for en
- VM: en virtuel maskine, som fungerer som en server
- Firewall: bestemmer hvilken netværkstrafik der må komme ind
- SSH: sikker terminalforbindelse til en server
- Docker Compose på server: kan bruges til at starte containere på serveren
- nginx/reverse proxy: kan sende trafik fra port 80/443 videre til en app
- Domæne fra one.com til serverens IP: DNS kan sættes til at pege domænet på serverens public IP
