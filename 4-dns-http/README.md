# DNS og HTTP(S)

DNS oversætter domænenavne til IP-adresser.

HTTP og HTTPS bruges, når browseren eller `curl` henter data fra en webserver.

## Begreber

- DNS-opslag: når et domænenavn slås op til en IP-adresse
- A record: peger et domæne på en IPv4-adresse
- CNAME: alias fra et navn til et andet navn
- MX: mailserver for et domæne
- TTL: hvor længe et DNS-svar må caches
- GET: henter data
- POST: sender data
- 2xx: succes
- 3xx: redirect
- 4xx: fejl hos klienten
- 5xx: fejl hos serveren
- Headers: metadata i en HTTP request eller response
- Cookies/session: bruges ofte til at huske en bruger mellem requests
- HTTPS: HTTP med kryptering via TLS
