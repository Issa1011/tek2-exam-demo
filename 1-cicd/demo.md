# Demo

1. Åbn projektet på GitHub.
2. Gå til fanen `Actions`.
3. Vælg workflowet `Java Maven CI`.
4. Tryk på `Run workflow`.
5. Åbn kørslen og vis job og steps.
6. Forklar at Maven cache er slået til med `cache: maven`.

Hvis workflowet fejler, kan jeg stadig forklare filen og vise, hvordan CI/CD normalt virker.
