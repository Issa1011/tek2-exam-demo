# Linux-terminalen

Terminalen bruges til at skrive kommandoer til computeren.

En shell er programmet, der læser kommandoerne. På mange systemer bruges Bash eller Zsh.

## Begreber

- Terminal: vinduet hvor man skriver kommandoer
- Shell: programmet der fortolker kommandoerne
- Kommando: en instruktion til computeren
- Fil: data gemt med et navn
- Mappe: sted hvor filer kan ligge
- Pipe: sender output fra en kommando videre til en anden
- Redirect: sender output til en fil
- Filrettigheder: bestemmer hvem der må læse, skrive eller køre en fil
