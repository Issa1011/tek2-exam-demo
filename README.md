# tek2-exam-demo

Dette er et meget simpelt eksamens-demo projekt til mundtlig Teknologi 2 på datamatiker 3. semester.

Projektet er ikke lavet til produktion. Det bruges kun til:

- korte demonstrationer
- kommandoer jeg kan køre live
- screenshots som backup
- simple forklaringer til eksamen

Mine rigtige dispositioner er printet separat. Dette projekt er kun et støtteprojekt, så jeg hurtigt kan vise de tekniske emner.

Screenshots kan bruges som backup, hvis noget ikke virker live under eksamen.

## Emner

1. CI/CD og GitHub Actions
2. Docker
3. TCP/IP og Wireshark
4. DNS og HTTP(S)
5. Linux-terminalen
6. Cloud
